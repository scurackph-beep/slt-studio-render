# DJ The Unicorn

Reproductor local (By Sweet Little Trauma).

## Qué incluye (funcional)

- **Biblioteca persistente** en IndexedDB: las canciones no se pierden al cerrar la app
- **EQ/visualizer** atado al analyser de audio (sigue el ritmo)
- **Tocadiscos** con vinilo girando + brazo/aguja que baja al reproducir
- **Pro**: primeros 50 a **$5**, después **$10**
- **Pagos in-app** (UI): Apple Pay, Tarjeta, PayPal, Mercado Pago (unlock local hasta StoreKit/backend)
- **Admin dueño**: compradores, ban, espacio usado
- Código dueño: `Dientito2032`

## Abrir

Abrí `apps/dj-the-unicorn/app/index.html` en el navegador, o serví la carpeta:

```bash
npx --yes serve apps/dj-the-unicorn/app -p 5177
```

## iOS (Capacitor)

Pendiente de empaquetar cuando volvamos a la Mac con Xcode. El `webDir` debe apuntar a `app/`.
